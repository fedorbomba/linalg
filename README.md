# linalg

Библиотека линейной алгебры. Главная сущность - класс `linalg::Matrix`,
матрица произвольного размера. Все элементы хранятся в одном динамическом
массиве `double`, память резервируется с запасом так же, как это делает
`std::vector`.

## Структура

```
include/linalg/   заголовочные файлы (интерфейс библиотеки)
    matrix.hpp    класс Matrix: хранение, размер, вместимость, Гаусс
    functions.hpp свободные операторы и функции над матрицами
    linalg.hpp    подключает сразу всё
source/           реализация
    matrix.cpp    конструкторы, присваивание, память, доступ к элементам
    arithmetic.cpp операторы +, -, *, == и присваивание с арифметикой
    gauss.cpp     прямой и обратный ход, норма, след, определитель, ранг
    functions.cpp transpose, concatenate, invert, power, solve
    print.cpp     вывод матрицы в поток
```

## Как подключить

Библиотека подключается как git подмодуль, тогда в `CMakeLists.txt`
достаточно двух строк:

```cmake
add_subdirectory(linalg)
target_link_libraries(my_app PRIVATE linalg)
```

Дальше в коде:

```cpp
#include "linalg/linalg.hpp"

linalg::Matrix a = {{1, 2}, {3, 4}};
linalg::Matrix b = a * a + linalg::identity(2);
std::cout << b << std::endl;
```

## Возможности

Размер и состояние: `rows()`, `columns()`, `size()`, `capacity()`,
`empty()`, `begin()`, `end()`.

Изменение размера: `reshape()`, `reserve()`, `clear()`, `shrink_to_fit()`,
`swap()`. `reshape()` оставляет те элементы, которые влезали в прежний размер,
и обнуляет только новый хвост. Размер `0 x N` или `N x 0` недопустим, легальна
только пустая матрица `0 x 0`. Доступ к элементу - через оператор вызова:
`m(0, 2) = 7.0;`.

Арифметика: `+`, `-`, unary `+`/`-`, `*` (как произведение матриц, так и
умножение на число с обеих сторон), `+=`, `-=`, `*=`, `==`, `!=`.
Сравнение вещественных чисел идёт с точностью `linalg::EPS`, поэтому
`0.3 * 3` и `0.9` считаются равными.

Вычисления: `norm()` (норма Фробениуса), `trace()`, `det()`, `rank()`,
`gauss_forward()`, `gauss_backward()`, а также `transpose()`,
`concatenate()`, `identity()`, `invert()`, `power()` и `solve()`.

Прямой ход делит ведущую строку на её ведущий элемент, поэтому на диагонали
остаются единицы, а `det()` восстанавливает масштаб по произведению этих
ведущих. Обратный ход имеет смысл только после прямого, и `gauss_backward()`
проверяет это и бросает исключение, если матрица не ступенчатая.

## Исключения

Нештатные ситуации обрабатываются через `std::runtime_error`:
несовместимые размеры матриц в операциях, обращение к элементу вне матрицы
(`std::out_of_range`), попытка взять след, определитель или обратную у
неквадратной либо вырожденной матрицы.

Гарантия безопасности нестрогая: если исключение вылетело, инвариант
матрицы всё равно не нарушается - объект остаётся корректной матрицей,
просто операция не выполняется.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Тесты живут в отдельном репозитории, где эта библиотека подключена
как подмодуль.
